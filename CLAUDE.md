This project is about building a LLM evaluation platform. 

The tech stack is:
- Vite + JavaScript (frontend)
- Bulma (CSS framework)
- FastAPI (backend)
- PostgreSQL (database)

For all code it is important to be as precise and legible as possible. Please follow these guidelines:
- Use clear and descriptive variable names.
- write short comments to explain the purpose of code blocks and functions.
- avoid unnecessary complexity and nested code.
- write modular code by breaking down functionality into smaller functions or components that can be reused

For Python code:
- always add type hints to function signatures

For JavaScript code:
- use arrow function syntax for defining functions
- use array methods like map, filter, and reduce instead of for loops when working with arrays
- use const and let instead of var for variable declarations
- any reusable style should be defined as css classes. Do NOT use the same inline styles repeatedly. Inline-styles should only be used for small, specific changes, never for general, especially repeated styles.
- Always use template literals for string concatenation instead of the + operator
- always include proptype definitions for React components
